# 🛠️ Fix Simple Things Mod

**Fix Simple Things** is a lightweight Minecraft client-side mod that fixes small but frustrating issues and inconsistencies in the base game.  
It doesn't add flashy new content — instead, it smooths out weird vanilla logic and makes things behave the way you'd *expect* them to.

---

## **Attention!** 
This mod only works on the client-side. Do  **not** use it on public servers, as it may cause issues or unexpected behavior.

---

## 🔧 Current Fixes

### ✅ Nylium Can Be Turned Into Path Blocks
You can now right-click Nylium blocks with a shovel to create **Nylium Path** blocks — just like Dirt or Grass!  
The new block retains Nylium-like properties, but looks and behaves like a proper path.

### 🚧 Stone & Cobblestone Can Be Smelted in "Blast Furnace" **(This will be changed to a custom blokk)**
Blast furnaces can now smelt **Stone** into **Smooth Stone**, as they logically should.  
No more switching back to the regular furnace just for that one item!

## 🧱 Planned Fixes & Vanilla Oddities

Here are a few vanilla Minecraft quirks that might get addressed in future updates:

- 🔥 **You can't cook eggs.** Scrambled eggs, anyone?
- 🪓 **Axes don't disable tripwire hooks.** (They *should* break redstone mechanisms faster.)
- 🧱 **You can’t craft slabs back into blocks.** Say goodbye to accidental crafting loss.
- 🌱 **You can't compost cactus.** It's organic!
- 📦 **Shulker boxes don't work in hoppers properly.** Somewhat frustrating automation limit.
- 🐟 **Fish dropped from a bucket lose their custom name.** Why though?
- 🧭 **Clocks and compasses are useless in item frames in the Nether.** Some say... they scream for fixing.

## 🚀 Installation

0. Make sure, that [Fabric API](https://modrinth.com/mod/fabric-api) is installed on the correct Minecraft Version. (Mod's latest version is *1.21.4*)

1. Download the latest .jar from the Releases.

2. Place it in your Minecraft mods/ folder.

3. Launch the game using a Forge profile. Enjoy!
